# Director Kit

A starter package for new film and motion directors working with AI tools. It holds what we learned making six AI-assisted short films and a set of brand motion pieces (October 2026):

- the playbooks and directing retrospectives;
- seven agent skills for Claude Code and Codex;
- the tools that worked;
- real scripts from finished films.

**Start here:** [START_HERE.md](START_HERE.md). It has a 12-step learning path and the rules that cost us the most to learn.

- Setup: [SETUP.md](SETUP.md) · Plugins and services: [PLUGINS.md](PLUGINS.md) · For AI agents: [AGENTS.md](AGENTS.md)
- `guides/`: how we direct, from story to delivery
- `skills/`: install into your agent
- `tools/`: image jobs and local per-shot upscaling
- `examples/`: scripts from two finished films, to read and adapt

The guides are dated working records from our lab. Project IDs and links marked "lab file, not in kit" refer to material that is not published here.
